# Учебная программа по TypeScript

Комплексный курс по изучению TypeScript с подробными примерами кода и практическими упражнениями.

## О курсе

Этот курс предназначен для изучения основ TypeScript - языка программирования, который добавляет статическую типизацию к JavaScript. Программа разработана модульно, что позволяет изучать материал частями и практиковаться на конкретных примерах.

## Особенности курса

- ✅ Модульная структура - изучайте темы последовательно
- ✅ Подробные комментарии к каждой строке кода
- ✅ Практические примеры для каждой концепции
- ✅ Рабочий код, который можно запускать и тестировать
- ✅ Советы по оптимизации и повышению производительности
- ✅ Полная типизация TypeScript

## Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск отдельного модуля

```bash
# Например, запуск модуля 01
npm run module01

# Запуск модуля 05
npm run module05
```

### Компиляция всех модулей

```bash
npm run build
```

### Запуск скомпилированного кода

```bash
npm start
```

## Требования

- Node.js версии 18 или выше
- npm или yarn

## Советы по изучению

1. **Последовательность** - изучайте модули по порядку, каждый следующий опирается на предыдущие
2. **Практика** - запускайте код, экспериментируйте с примерами
3. **Комментарии** - внимательно читайте комментарии к коду
4. **Модификация** - изменяйте примеры, пробуйте разные варианты
5. **Производительность** - обращайте внимание на советы по оптимизации
