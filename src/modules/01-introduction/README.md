# Модуль 01: Введение в TypeScript и базовые типы данных

## Описание

Этот модуль знакомит с основами TypeScript и базовыми типами данных. TypeScript - это надмножество JavaScript с добавлением статической типизации, что помогает находить ошибки на этапе компиляции.

## Темы модуля

1. **Базовые типы данных**
   - `number` - числа (целые и с плавающей точкой)
   - `string` - строки
   - `boolean` - логические значения
   - `null` и `undefined` - специальные значения

2. **Расширенные типы**
   - `any` - любой тип
   - `unknown` - безопасная альтернатива any
   - `void` - отсутствие возвращаемого значения
   - `never` - функции, которые никогда не возвращают управление

3. **Литеральные типы**
   - Строковые литералы
   - Числовые литералы

4. **Типы-объединения**
   - Union types (`string | number`)
   - Type aliases (псевдонимы типов)

5. **Утверждение типа (Type Assertion)**
   - Синтаксис `as`
   - Синтаксис `<>`

6. **Типизация констант**
   - Использование `const`
   - Неизменяемость ссылок vs неизменяемость значений

## Запуск модуля

```bash
npm run module01
```

## Ключевые понятия

- **Статическая типизация** - проверка типов на этапе компиляции
- **Вывод типов** - TypeScript автоматически определяет типы
- **Строгая типизация** - явное указание типов для безопасности

## Советы по производительности

1. Используйте строгую типизацию для лучшей оптимизации компилятором
2. Избегайте `any` - используйте `unknown` для неизвестных типов
3. Используйте `const` для неизменяемых значений
4. Литеральные типы помогают предотвратить ошибки
