# Модуль 07: Объекты

## Описание

Этот модуль охватывает работу с объектами в TypeScript, включая создание, манипуляцию, интерфейсы и классы.

## Темы модуля

1. **Создание объектов**
2. **Доступ к свойствам** (точечная и скобочная нотация, optional chaining)
3. **Изменение объектов**
4. **Методы объектов**
5. **Интерфейсы и типы**
6. **Вложенные объекты**
7. **Деструктуризация**
8. **Spread и Rest операторы**
9. **Методы Object** (keys, values, entries, assign, freeze, seal)
10. **Перебор свойств**
11. **Классы** (наследование)
12. **Геттеры и сеттеры**
13. **Статические свойства и методы**
14. **Практические примеры**

## Запуск модуля

```bash
npm run module07
```

## Советы по производительности

1. Используйте Object.keys/values/entries вместо for...in
2. Spread создает поверхностную копию
3. Деструктуризация не влияет на производительность
4. Используйте optional chaining (?.) для безопасности
5. Статические методы эффективнее методов экземпляра
