# Модуль 05: Функции

## Описание

Этот модуль охватывает различные аспекты работы с функциями в TypeScript.

## Темы модуля

1. **Объявление функций**
   - Function declaration
   - Function expression
   - Arrow functions

2. **Параметры**
   - Обязательные параметры
   - Опциональные параметры
   - Параметры по умолчанию
   - Rest параметры

3. **Возвращаемые значения**
   - Явная типизация
   - Void
   - Union types

4. **Функции высшего порядка**
   - Функции как параметры
   - Функции как возвращаемые значения

5. **Callback функции**

6. **Замыкания (Closures)**
   - Приватные переменные
   - Сохранение состояния

7. **Рекурсия**
   - Базовые и рекурсивные случаи
   - Примеры применения

8. **Перегрузка функций**

9. **Generic функции**
   - Обобщенные типы
   - Ограничения типов

10. **Методы vs Функции**

## Запуск модуля

```bash
npm run module05
```

## Советы по производительности

1. Используйте стрелочные функции для коротких операций
2. Кэшируйте результаты рекурсивных функций
3. Избегайте глубокой рекурсии
4. Используйте rest параметры вместо arguments
5. Generic функции обеспечивают типобезопасность
