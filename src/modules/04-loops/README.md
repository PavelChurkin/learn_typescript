# Модуль 04: Циклы

## Описание

Этот модуль охватывает различные типы циклов в TypeScript и их применение.

## Темы модуля

1. **Цикл for**
   - Классический синтаксис
   - Вложенные циклы
   - Различные шаги

2. **Цикл while**
   - Проверка условия перед итерацией
   - Неопределенное количество итераций

3. **Цикл do-while**
   - Проверка условия после итерации
   - Минимум одно выполнение

4. **For...of**
   - Итерация по значениям
   - Работа с массивами и строками
   - Доступ к индексу через entries

5. **For...in**
   - Итерация по ключам объекта
   - Использование с объектами

6. **Break и Continue**
   - Прерывание цикла
   - Пропуск итерации
   - Метки для вложенных циклов

7. **Методы массивов**
   - forEach, map, filter
   - reduce, find
   - some, every

8. **Бесконечные циклы**
   - Предотвращение зацикливания
   - Условия выхода

9. **Практические примеры**
   - Факториал
   - Числа Фибоначчи
   - Проверка на простое число

## Запуск модуля

```bash
npm run module04
```

## Советы по производительности

1. Выбирайте правильный тип цикла для задачи
2. Кэшируйте длину массива при использовании for
3. Используйте методы массивов для функционального стиля
4. Используйте break и continue для оптимизации
5. For...of обычно быстрее forEach
