# Модуль 06: Массивы

## Описание

Этот модуль охватывает работу с массивами в TypeScript, включая создание, манипуляцию и методы обработки массивов.

## Темы модуля

1. **Создание массивов**
2. **Типизация массивов**
3. **Доступ к элементам**
4. **Изменение массива** (push, pop, shift, unshift)
5. **Методы поиска** (indexOf, includes, find, findIndex)
6. **Фильтрация и преобразование** (filter, map, flatMap)
7. **Методы агрегации** (reduce, reduceRight)
8. **Методы проверки** (every, some)
9. **Сортировка** (sort, reverse)
10. **Извлечение** (slice, splice)
11. **Объединение** (concat, spread, join)
12. **Многомерные массивы** (flat)
13. **Деструктуризация**
14. **Практические примеры**

## Запуск модуля

```bash
npm run module06
```

## Советы по производительности

1. Используйте методы массивов вместо циклов for
2. Избегайте множественных проходов по большим массивам
3. find() эффективнее filter()[0]
4. Используйте Set для удаления дубликатов
5. includes() быстрее indexOf() !== -1
