# Модуль 02: Переменные и операторы

## Описание

Этот модуль охватывает способы объявления переменных и различные типы операторов в TypeScript.

## Темы модуля

1. **Объявление переменных**
   - `var` (устаревший способ)
   - `let` (для изменяемых переменных)
   - `const` (для неизменяемых привязок)

2. **Область видимости**
   - Блочная область видимости
   - Функциональная область видимости

3. **Арифметические операторы**
   - Сложение, вычитание, умножение, деление
   - Остаток от деления, возведение в степень
   - Инкремент и декремент

4. **Операторы присваивания**
   - `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`

5. **Операторы сравнения**
   - Строгое и нестрогое равенство
   - Больше, меньше, больше или равно, меньше или равно

6. **Логические операторы**
   - AND (`&&`), OR (`||`), NOT (`!`)
   - Короткое замыкание

7. **Операторы объединения**
   - Nullish coalescing (`??`)
   - Optional chaining (`?.`)

8. **Строковые операторы**
   - Конкатенация
   - Шаблонные строки

9. **Тернарный оператор**
   - Условные выражения

10. **Оператор typeof**
    - Определение типа переменной

## Запуск модуля

```bash
npm run module02
```

## Советы по производительности

1. Используйте `const` по умолчанию, `let` только при необходимости
2. Избегайте `var`
3. Используйте строгое сравнение (`===`)
4. Используйте короткое замыкание для оптимизации
5. Предпочитайте шаблонные строки конкатенации
