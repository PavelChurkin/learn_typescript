# Модуль 03: Условные конструкции

## Описание

Этот модуль рассматривает различные способы создания условной логики в TypeScript.

## Темы модуля

1. **Оператор if**
   - Простой if
   - if-else
   - if-else if-else

2. **Вложенные условия**
   - Вложенные if
   - Оптимизация с логическими операторами

3. **Оператор switch**
   - Базовый синтаксис
   - Группировка случаев (fall-through)
   - Switch со строками

4. **Тернарный оператор**
   - Простые условия
   - Вложенные тернарные операторы

5. **Логические выражения**
   - Комбинация условий
   - Логические операторы

6. **Проверка на null и undefined**
   - Различные способы проверки
   - Nullish coalescing

7. **Guard Clauses**
   - Ранний выход из функции
   - Уменьшение вложенности

8. **Type Guards**
   - typeof
   - instanceof
   - Пользовательские type guards

## Запуск модуля

```bash
npm run module03
```

## Советы по производительности

1. Используйте guard clauses для уменьшения вложенности
2. Switch может быть быстрее множественных if-else
3. Используйте логические операторы для коротких проверок
4. Type guards помогают TypeScript оптимизировать код
5. Избегайте глубокой вложенности
